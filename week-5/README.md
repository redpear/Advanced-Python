# Tic-Tac-Toe with NumPy

This is my Week 5 Advanced Python assignment. I created a two-player Tic-Tac-Toe game using a 3x3 NumPy array.

## How to Run

1. Install Python 3 and NumPy.
2. Open a terminal in the project folder.
3. Install NumPy if needed:
   ```bash
   python3 -m pip install numpy
   ```
4. Run the game:
   ```bash
   python3 tic_tac_toe.py
   ```

## How to Play

Player X goes first, followed by Player O. Each player enters a row number and a column number from 0 to 2. A move must be in an empty square. The game ends when a player gets three symbols in a row, column, or diagonal, or when the board fills up and the game is a draw.

## Features

- Uses a 3x3 NumPy array for the board
- Alternates between two players
- Checks for invalid or occupied positions
- Detects wins and draws
